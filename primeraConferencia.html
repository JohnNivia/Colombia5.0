Colombia 5.0 – Conferencia 1

Game UI Systems

Nombre de la conferencia: Game UI Systems: de pantallas bonitas a interfaces que funcionan

Conferencista: Andres Felipe Pisso Tobar

Tema principal: Interfaces en Figma

Resumen

En esta conferencia se habló sobre el uso de Figma para el diseño de interfaces de videojuegos, también explicaron cómo organizar los elementos visuales para evitar que la interfaz se vea sobrecargada, la importancia de utilizar iconos adecuados y consistentes, y cómo construir una mini base de Game UI mediante componentes reutilizables, estados y patrones de diseño que faciliten el desarrollo y mejoren la experiencia del usuario.
