Colombia 5.0 conferencia numero 1

Primera conferencia

Nombre de la conferencia: Game UI Systems: de pantallas bonitas a interfaces que funcionan

Nombre del conferencista: Andres Felipe Pisso Tobar

Tema principal: Interfaces figma

Resumen

En esta conferencia se hablo sobre el uso de Figma para el diseño de interfaces de videojuegos, tambien explicaron cómo organizar los elementos visuales para evitar que la interfaz se vea sobrecargada, la importancia de utilizar iconos adecuados y consistentes, y como construir una mini base de Game UI mediante componentes reutilizables, estados y patrones de diseño que faciliten el desarrollo y mejoren la experiencia del usuario.
