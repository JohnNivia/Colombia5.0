Glosario

Inglés Español Definición
Algorithm Algoritmo Conjunto de instrucciones ordenadas y finitas que permiten resolver un problema o realizar una tarea específica dentro de un sistema computacional.
Artificial Intelligence Inteligencia Artificial Rama de la informática que desarrolla sistemas capaces de realizar tareas que normalmente requieren inteligencia humana, como el aprendizaje, el razonamiento y la toma de decisiones.
API Interfaz de Programación de Aplicaciones Conjunto de reglas y protocolos que permite que diferentes aplicaciones o sistemas se comuniquen entre sí e intercambien datos de forma estandarizada.
Bandwidth Ancho de banda Capacidad máxima de transmisión de datos a través de una red o canal de comunicación, generalmente medida en bits por segundo (bps).
Blockchain Cadena de bloques Tecnología de registro distribuido que almacena información en bloques encadenados de forma cronológica, garantizando la inmutabilidad y transparencia de los datos.
Cloud Computing Computación en la nube Modelo de prestación de servicios tecnológicos a través de internet que permite acceder a recursos de cómputo, almacenamiento y software sin necesidad de infraestructura física propia.
Cybersecurity Ciberseguridad Conjunto de prácticas, tecnologías y procesos diseñados para proteger sistemas, redes y datos digitales frente a ataques, daños o accesos no autorizados.
Database Base de datos Sistema organizado para almacenar, gestionar y recuperar información de manera estructurada, permitiendo el acceso eficiente a grandes volúmenes de datos.
Deep Learning Aprendizaje profundo Subconjunto del aprendizaje automático basado en redes neuronales artificiales con múltiples capas, capaz de aprender representaciones complejas de datos sin intervención humana.
DevOps DevOps Metodología que integra el desarrollo de software y las operaciones de TI para acortar los ciclos de desarrollo, mejorar la colaboración y entregar software de alta calidad continuamente.
Encryption Cifrado Proceso de transformar información legible en un formato codificado mediante algoritmos matemáticos, asegurando que solo los destinatarios autorizados puedan acceder a ella.
Firewall Cortafuegos Sistema de seguridad de red que monitorea y controla el tráfico de datos entrante y saliente según reglas de seguridad predefinidas, bloqueando accesos no autorizados.
Framework Marco de trabajo Estructura base de software que proporciona componentes reutilizables, herramientas y convenciones para facilitar el desarrollo de aplicaciones de manera estandarizada.
Internet of Things Internet de las Cosas Red de dispositivos físicos conectados a internet que recopilan, transmiten e intercambian datos entre sí de forma automatizada para optimizar procesos en diversos entornos.
Latency Latencia Tiempo de retardo que transcurre entre el envío de una solicitud y la recepción de la respuesta correspondiente en una red o sistema de comunicaciones.
Machine Learning Aprendizaje automático Rama de la inteligencia artificial que permite a los sistemas aprender y mejorar automáticamente a partir de la experiencia sin ser programados explícitamente para cada tarea.
Microservices Microservicios Arquitectura de software que estructura una aplicación como un conjunto de servicios pequeños e independientes, cada uno ejecutándose en su propio proceso y comunicándose mediante APIs.
Neural Network Red neuronal Modelo computacional inspirado en el funcionamiento del cerebro humano, compuesto por nodos interconectados que procesan información para reconocer patrones y realizar predicciones.
Open Source Código abierto Modelo de desarrollo de software cuyo código fuente es de acceso público, permitiendo a cualquier persona estudiarlo, modificarlo y distribuirlo libremente bajo licencias específicas.
Phishing Suplantación de identidad Técnica de ingeniería social utilizada por ciberdelincuentes para engañar a los usuarios y obtener información confidencial mediante correos electrónicos o sitios web fraudulentos.
Protocol Protocolo Conjunto de reglas y estándares que regulan la comunicación y el intercambio de datos entre dispositivos o sistemas dentro de una red informática.
Repository Repositorio Almacenamiento centralizado donde se guarda, organiza y gestiona el código fuente de un proyecto de software, permitiendo el control de versiones y la colaboración entre desarrolladores.
Scalability Escalabilidad Capacidad de un sistema de software o infraestructura para adaptarse y mantener su rendimiento al incrementar la carga de trabajo, el número de usuarios o el volumen de datos.
Server Servidor Computador o programa que proporciona recursos, datos o servicios a otros dispositivos denominados clientes a través de una red de comunicaciones.
Software Development Desarrollo de software Proceso que comprende el diseño, programación, prueba y mantenimiento de aplicaciones o sistemas informáticos para satisfacer necesidades específicas de usuarios u organizaciones.
Startup Empresa emergente Empresa de reciente creación con un modelo de negocio innovador y escalable, generalmente vinculada al sector tecnológico y con alto potencial de crecimiento en el mercado.
Token Token Unidad mínima de representación digital de un activo o dato, utilizada en sistemas de autenticación, criptomonedas y modelos de lenguaje para segmentar y procesar información.
UI/UX Interfaz y experiencia de usuario Disciplinas del diseño digital: UI se enfoca en los elementos visuales e interactivos de una aplicación, mientras que UX abarca la experiencia global del usuario durante su interacción con el producto.
Virtualization Virtualización Tecnología que permite crear versiones virtuales de recursos físicos como servidores, redes o sistemas operativos, optimizando el uso del hardware y facilitando la administración de infraestructuras.
Vulnerability Vulnerabilidad Debilidad o fallo en un sistema, aplicación o red que puede ser explotado por agentes maliciosos para comprometer la seguridad, integridad o disponibilidad de la información.
